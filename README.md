# Aditya Tripathi — Portfolio Website

A personal portfolio built with plain HTML, CSS and JavaScript. The files are kept separate so you can edit the content and design without needing a framework or build tools.

## Folder structure

```text
aditya-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    └── (add your profile photo or project screenshots here)
```

## Run it locally

1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Where to make changes

- **Personal details, About, projects, education, certifications and links:** `index.html`
- **Colors, fonts, spacing, layout and responsive design:** `css/style.css`
- **Mobile navigation and footer year:** `js/script.js`
- **Images and screenshots:** place files in `assets/`, then reference them from `index.html`.

## Before publishing

- Check your email and LinkedIn links.
- Add links to each project's GitHub repository when ready.
- Add screenshots to the project cards if you want.
- Update your education, certifications and skills as they change.
- Phone number is intentionally not included.
- The city-rank achievement has been removed.

## Publish

You can deploy this static website using GitHub Pages or Netlify. No backend or package installation is required.
